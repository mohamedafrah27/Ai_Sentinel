# Safe Browsing Practices and Defense-in-Depth

## Recommended User Practices for Safe Web Navigation
Adopting defense-in-depth browsing habits provides robust protection against even sophisticated phishing and website spoofing campaigns:

### 1. Manual Address Bar Verification
- Never click direct links in unexpected emails, text messages, or direct messages.
- Always inspect the root domain (the characters immediately preceding the TLD and first forward slash).
- Bookmark authentic, frequently visited banking, email, and social portals.

### 2. Password Manager Enforcement
Modern password managers use domain-bound credential matching. If you land on a spoofed domain (e.g., `paypal-verify.xyz` instead of `paypal.com`), the password manager will refuse to auto-fill credentials, immediately alerting you to a deceptive site.

### 3. Multi-Factor Authentication (MFA)
Enable phishing-resistant MFA methods such as FIDO2 / WebAuthn hardware security keys or authenticator apps rather than SMS-based OTPs, which are vulnerable to adversary-in-the-middle phishing proxy kits.

### 4. Continuous Threat Monitoring
Utilize real-time browser security extensions (such as AI Sentinel) that actively inspect heuristics, machine learning signals, and known threat blacklists before credentials are submitted.
